# Paquete comercial — Pedacito de Cielo

Este directorio reúne material para presentar el proyecto como caso de estudio y como base reutilizable para negocios gastronómicos. No sustituye la documentación técnica ni afirma resultados comerciales que todavía no han sido medidos.

## Documentos

- [Presentación comercial](commercial-overview.md): problema, solución, beneficios y proceso.
- [Caso de estudio](case-study.md): contexto, objetivos, decisiones y resultados del desarrollo.
- [Oferta de producto](product-offer.md): alcance de los planes sin precios.
- [Guía de portafolio](portfolio.md): relato, capturas requeridas y ficha técnica.
- [Evolución a producto reutilizable y SaaS](product-evolution.md): etapas futuras sin implementar multi-tenant.

## Uso recomendado

1. Completar las capturas indicadas en la guía de portafolio.
2. Sustituir los campos `[POR COMPLETAR]` únicamente con información confirmada.
3. Ajustar el alcance de cada propuesta a las necesidades reales del cliente.
4. Mantener separados los beneficios esperados de los resultados medidos.
5. No ofrecer como disponible ninguna capacidad marcada como futura.
