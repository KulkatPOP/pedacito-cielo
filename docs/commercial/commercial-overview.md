# Presentación comercial

## Pedacito de Cielo

Una experiencia digital para presentar una propuesta gastronómica, facilitar el descubrimiento de productos y mantener la información del negocio administrable sin editar código.

## Problema que resuelve

Muchos negocios gastronómicos dependen de publicaciones aisladas, mensajes repetitivos y catálogos difíciles de mantener. Esto puede dificultar que un cliente encuentre rápidamente productos, precios, disponibilidad, horarios, ubicación y un canal claro para realizar su consulta.

Además, cuando cada actualización requiere intervención técnica, el sitio pierde vigencia y el negocio depende de terceros para cambios cotidianos.

## Solución propuesta

Pedacito de Cielo centraliza la presentación comercial del negocio en un sitio responsive conectado a un panel administrativo. El visitante puede conocer la marca, explorar el catálogo y continuar la conversación por WhatsApp. El administrador puede mantener productos, promociones, contenido y respuestas del chatbot mediante una interfaz protegida.

La página pública prioriza Supabase como fuente de información y dispone de un respaldo local para conservar contenido esencial ante fallos de conexión.

## Funcionalidades principales

- Sitio público responsive con identidad visual gastronómica.
- Hero comercial, propuesta de valor, historia, contacto y ubicación.
- Catálogo por categorías con precio, disponibilidad, etiquetas y productos destacados.
- Solicitud de productos mediante WhatsApp con mensaje contextual.
- Chatbot Cielito con preguntas rápidas y respuestas administrables.
- Panel protegido para gestionar productos, promociones, contenido y configuración.
- Subida y previsualización de imágenes mediante Supabase Storage.
- Estados de producto: disponible, agotado y oculto.
- Base SEO con metadatos, Open Graph y datos estructurados de negocio local.
- Diseño adaptable para móvil, tablet y escritorio.
- Fallback local para la experiencia pública.
- Documentación de seguridad, mantenimiento, pruebas y lanzamiento.

## Beneficios para negocios gastronómicos

- Reúne información comercial dispersa en un punto de consulta propio.
- Reduce fricción entre el interés del visitante y el contacto por WhatsApp.
- Facilita mantener catálogo, disponibilidad y contenido sin modificar código.
- Refuerza identidad, confianza y claridad antes de la compra.
- Permite ocultar temporalmente productos sin eliminar información.
- Mantiene una base técnica preparada para nuevas integraciones.

Estos beneficios describen el propósito del producto; no representan métricas de ventas obtenidas.

## Tecnologías

- React y React Router para interfaz y navegación.
- Vite para desarrollo y compilación.
- Supabase Auth, PostgreSQL, Realtime y Storage.
- CSS responsive organizado en estilos públicos y administrativos.
- JSON local como respaldo operativo.
- Node Test Runner para pruebas básicas de prioridad y catálogo.

## Proceso de implementación

1. Descubrimiento del negocio, datos confirmados y objetivos.
2. Organización del contenido y definición de experiencia pública.
3. Construcción del catálogo y recorridos de contacto.
4. Integración del CMS, autenticación, base de datos y almacenamiento.
5. Configuración de fallback y manejo de errores.
6. Revisión responsive, SEO, seguridad y accesibilidad básica.
7. Pruebas, documentación, capacitación y checklist de lanzamiento.
8. Validación en ambiente de prueba antes de publicar.

## Alcance responsable

La solución actual no incluye pagos en línea, newsletter real, CRM con datos personales, analítica global ni arquitectura multi-tenant. Esas capacidades requieren evaluación, consentimiento, seguridad y alcance propios.
